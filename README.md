# claude-buffado

Ambiente de desenvolvimento com IA que amplia o Claude Code e o Codex sem substituí-los.
Especificação completa em [spec.md](spec.md).

| Etapa | Descrição | Status |
|---|---|---|
| 1. Voz universal | Atalho global → fala → texto inserido no campo com foco. Local, na GPU. | ✅ [`etapa1-voz/`](etapa1-voz/) |
| 2. Contas do Claude Code | Alternar entre contas autenticadas sem logout/login. | Planejada |
| 3. Terminal unificado | Voz contínua, seleção de modelo/esforço, delegação Claude Code → Codex. | Planejada |
